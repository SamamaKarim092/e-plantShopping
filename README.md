# Project Overview
For my final project in the Coursera React course, I built a dynamic e-commerce website where users can interact with products, adding them to a shopping cart, adjusting quantities, and seeing real-time calculations. I chose to use Vite as the build tool for this project, transitioning from Webpack which I used in my previous projects, to explore the differences in performance and ease of use. Additionally, I incorporated JWT tokens and API integration to handle user authentication and data fetching, which further expanded my understanding of full-stack web development concepts.

## Features
Add to Cart: Users can add products to their shopping cart, with a smooth and interactive UI.

Remove Items: Easily remove any unwanted items from the cart.

Quantity Adjustment: The quantity of products in the cart can be increased or decreased, with live updates to the total.

Price Calculation: The website automatically calculates the total price based on the products and quantities in the cart.

Authentication: JWT tokens are used for secure login and session management, providing a more robust user experience.
